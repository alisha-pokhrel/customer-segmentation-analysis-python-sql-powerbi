# Customer Segmentation Analysis

A data analytics project using **Python, SQL, and Power BI** to understand customer behaviour, purchasing patterns, and generate actionable business insights.

## Project Overview

The goal of this project is to analyze customer transaction data, identify purchasing patterns, and segment customers based on their behaviour.

The project follows an end-to-end data analytics workflow, starting with data cleaning and exploratory analysis and progressing toward customer segmentation and dashboard development.

## Tools & Technologies

- **Python:** Data cleaning, exploratory data analysis (EDA), and customer segmentation.
- **SQL:** Data querying and analysis.
- **Power BI:** Interactive dashboards and data visualization.
- **Jupyter Notebook:** Python development and documentation.

## Project Workflow

1. Data Understanding
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Feature Engineering and RFM Analysis
5. Customer Segmentation
6. SQL Analysis
7. Power BI Dashboard
8. Business Insights and Recommendations
